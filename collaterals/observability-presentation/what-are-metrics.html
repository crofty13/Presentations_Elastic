20M+PromQL deployments: the de facto query language. Elastic speaks it natively.
COUNTERhttp_requests_total

Monotonically increasing. Only ever goes up. Rate of change reveals throughput.

GAUGEcpu_usage_percent

Point-in-time snapshot. Can go up or down: memory, queue depth, active connections.

HISTOGRAMrequest_duration_seconds

Distribution across buckets. Reveals p50, p95, p99 latency from a single metric.

Alerts fire on metrics thresholds. Dashboards visualize metrics trends. PromQL is the query language that makes it all work. 20M+ deployments speak it natively, and so does Elastic.
Three simple types

Counters only go up, gauges snapshot a point in time, histograms give you p50, p95 and p99 from one metric. Every alert and every dashboard runs on these three.

Hold onto that

These primitives have not changed since Prometheus. What changes next is the volume: AI multiplies how many series each of them produces.
