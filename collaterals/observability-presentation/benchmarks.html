One level deeper

The TS command in ES|QL aggregates per time series, then groups: time-series math in a single pipeline, over series kept in _tsid and time order.

How

Series are sorted on disk. A query reads one column, skips non-matching blocks before decoding them (DIM filters), and aggregates in a single vectorized pass.

One level deeper

The _id is derived from the series and timestamp, sequence numbers are trimmed, and codec blocks widened from 128 to 512 elements catch repeating patterns like IPs.

How

Store less, compute the rest. IDs derived instead of stored, inverted indices replaced by lightweight skippers, codecs tuned to the shapes metrics take.

Methodology

Default configurations for every system (Prometheus v3.11.1, Mimir v3.0.6, ClickHouse v26.3), an open-source workload generator inspired by TSBS, disclosed EC2 hardware. ClickHouse lacks native time-series aggregations and counter-reset detection, so those comparisons are directional. Source: Elastic Search Labs.
